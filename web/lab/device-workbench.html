LANGKAH WAJIB · Verifikasi Pemilik (satu kali)

OLT sudah bisa dicatat di daftar perangkat. Untuk koneksi SSH nyata, isi password perangkat dan kode pemilik melalui halaman ini. Jangan kirim keduanya ke ChatGPT.

Why is this required? This private lab preview is not yet protected by the production IPAT Admin login. This temporary code proves access to the owner VPS before IPAT sends your SSH password to the OLT. It is not the OLT password and is invalidated after the first successful device verification.

Cara mendapatkan kode: Tekan Copy Command, jalankan perintah tersebut di Terminal Mac Anda. Terminal akan menampilkan pesan IPAT: KODE TERSALIN, bukan kodenya. Langsung kembali ke kolom di bawah dan tekan Command + V; jangan menyalin teks lain setelah menjalankan perintah. Bila Terminal menampilkan kesalahan SSH atau tidak menampilkan pesan berhasil, jangan lanjutkan koneksi.

set -o pipefail; ssh -o BatchMode=yes -o ConnectTimeout=8 ipat-lab 'cat /home/openai/.local/share/ipat/r945-connection/bootstrap-token' | pbcopy && printf 'IPAT: KODE TERSALIN. Kembali ke browser dan tekan Command+V di kolom Owner Code.\n'

Copy Command hanya menyalin PERINTAH. Setelah perintah dijalankan di Terminal, clipboard berisi KODE. Perintah tidak menampilkan kode atau password.

Future production flow: a verified IPAT Admin session with tenant permissions will replace this temporary lab-only step.

Profil yang diuji di halaman ini hanya SSH 10.10.13.233:321. Port Telnet laboratorium :323 adalah layanan berbeda dan belum menjadi adapter koneksi otomatis. Aksi perangkat fisik tetap baca-saja.
